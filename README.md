# SOSDPZ · Cobertura Operativa Bomberos DPZ

Herramienta web interactiva para simular el estado operativo de los parques de bomberos de la Diputación Provincial de Zaragoza.

- **Panel lateral**: ajusta el nº de bomberos activos por parque.
- **Mapa**: 292 municipios coloreados según el tiempo de intervención del parque asignado (verde ≤15 min, amarillo 15-35, naranja 35-45, rojo 45-55, rojo oscuro >55).
- **Cascada**: si un parque está a 0 bomberos, cada mun pasa a su 2º parque asignado; si el 2º también está cerrado, al 3º.
- **Datos**: población INE 2022, superficies calculadas por polígono, tiempos de intervención según PDF oficial DPZ.
